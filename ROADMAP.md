# Product Roadmap 🗺️

Future development plans and extension goals for **BharatEvents**.

---

## 1. Phase 1: Core Framework (Completed)
*   [x] Set up decoupled backend and frontend monorepo workspaces.
*   [x] Establish MongoDB connection via Mongoose ODM.
*   [x] Implement basic event registration and list APIs.
*   [x] Integrate Tailwind CSS, TanStack Query, and React Hook Form on the frontend.

---

## 2. Phase 2: Premium Upgrades (Completed)
*   [x] Redesign layout with announcement banners, hero section, and category pills.
*   [x] Build a 3-step checkout wizard with ticket selection and promo coupon validation.
*   [x] Design custom SVG charts to track registration trends.
*   [x] Add system diagnostics and activity loggers.
*   [x] Populate the database with 100+ events across 13 Indian cities using an upgraded seeder script.

---

## 3. Phase 3: Integration (Upcoming)
*   [ ] **Payment Gateways**: Integrate Razorpay test gateway for paid event VIP Passes.
*   [ ] **OAuth Sign-in**: Allow users to authenticate with Google and GitHub.
*   [ ] **CSV/PDF Tickets**: Auto-generate PDF registration tickets.
*   [ ] **Calendar APIs**: Export calendar invites directly.

---

## 4. Phase 4: Production Scale (Upcoming)
*   [ ] **Docker Setup**: Package the app into containers using Docker Compose.
*   [ ] **Caching**: Integrate Redis to cache common event queries.
*   [ ] **Notification Service**: Set up automatic email notifications using Resend.
